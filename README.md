# UniFind - Lost and Found System

A web-based Lost and Found system for university students, built as part of the SE3107 practical (Group 08).

## Features

- Report lost items
- Report found items
- Browse and search listed items
- Simple and easy-to-use interface

## Tech Stack

- **Front-end:** React (Vite), CSS
- **Back-end:** Node.js, Express
- **Database:** MySQL

## Project Structure

```
backend/                  -> Server and database files
unifind-frontend-code/    -> React front-end
```

## How to Run

### Back-end
```bash
cd backend
npm install
node src/server.js
```

### Front-end
```bash
cd unifind-frontend-code/unifind-frontend
npm install
npm run dev
```
